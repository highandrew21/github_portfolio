# Andrew Aguilar — Electrical Engineering Portfolio

Personal portfolio site built with plain HTML/CSS, hosted on GitHub Pages.

**Live site:** https://<your-username>.github.io/portfolio/ (replace with your GitHub username after you publish)

## Setup (GitHub Pages)

1. Create a new repo named `portfolio` on GitHub (public).
2. Push these files:

```bash
git init
git add .
git commit -m "Initial portfolio site"
git branch -M main
git remote add origin https://github.com/<your-username>/portfolio.git
git push -u origin main
```

3. Repo → Settings → Pages → Source: `main` branch, `/ (root)` folder → Save.
4. Site goes live in a minute or two at the URL above.

## Structure
- `index.html` — entire site (single file, no build step)
- `images/` — optimized project photos
